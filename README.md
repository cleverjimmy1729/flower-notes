# 花间 · 离线植物手记 🌸

**让每一次看见，都成为一次相遇。**

一款纯离线的植物观察手记应用：查看常见植物图鉴、拍照识别身边的花草、记录每次相遇，并按花期推荐已收录的上海赏花地点。照片、样式与程序全部内嵌在单个 HTML 文件中，双击即用、无需安装。

## ✨ 功能

- **植物图鉴**：收录常见植物与上海地区花期参考，支持按名称、学名或属名搜索
- **照片识别**（可选联网）：
  - **DeepSeek** 视觉模型——默认 `deepseek-flash`，返回中文候选、简介与辨识线索
  - **Pl@ntNet**——返回物种候选与匹配分数
  - 仅在点击"识别这株植物"时发送所选照片，不发送地点与手记；密钥只存页面内存，刷新即清
- **手记记录**：照片、植物名称、发现地点、坐标、日期与笔记，保存在浏览器 IndexedDB
- **赏花推荐**：按常见花期、植物种类与直线距离推荐已收录的上海赏花地点（其他城市不会虚构推荐）
- **备份与恢复**：导出 / 导入含照片的 JSON 备份；记录中不包含任何密钥

## 🚀 使用

双击打开 **`花间·植物手记.html`**（建议 Chrome 或 Edge）。

- 离线可做：查图鉴与花期、手动记录、保存照片与地点、距离筛选赏花地、导入导出备份
- 联网识别：左侧"识别接口"选择 DeepSeek 或 Pl@ntNet，填入自己的 API Key 后上传照片识别
- `file://` 直连第三方接口可能受 CORS 限制，高级设置中可填写支持跨域的兼容代理（仅允许 HTTPS 或本机 localhost）

> ⚠️ 清理浏览器数据、更换浏览器或移动 HTML 文件可能影响记录访问，请定期导出备份。


## 🔧 源文件与构建

| 文件 | 说明 |

| `index.template.html` | 页面结构（`/*__CSS__*/` 等占位符） |
